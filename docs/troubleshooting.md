# Troubleshooting

- **No voice** — Click anywhere to arm audio. Check browser autoplay. Toggle voice on start screen.
- **Live LLM silent** — Pollinations rate limit (3.2s throttle). Use Local Neural for offline.
- **Blank canvas** — Check console. Ensure seed is numeric.
- **EXE blocked by SmartScreen** — Unsigned. More info → Run anyway.
- **Build OOM** — `vite-plugin-singlefile` needs ~2 GB RAM. Close other apps.
